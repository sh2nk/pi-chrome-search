# P15 — M15: host portability layer

Date: 2026-11-06
Owner: orchestrator
Verdict: **PASS** (V15.1–V15.6)

Plan: `PLAN-v2.md` §2.1 (PO1–PO6) and §4 (P15-A..P15-D). This phase makes "the host" an
interface before P11 (notifications) and P12 (PDF) start leaving the process.

## What landed

- New `src/runtime/host.ts`: `platform()` seam, `profileCandidates()` for Linux/macOS/Windows,
  `homeDir`/`expandHome`/`tildify`/`agentDir`, `capability()` (declared names, `access(X_OK)`,
  memoised, injectable, never spawns), `isProcessAlive()` (`kill(pid, 0)`), browser-brand detection
  and the brand-aware `cdpAllowHint()`.
- Linux profile table is byte-identical to the old `PROFILE_SUFFIXES`; `PI_CHROME_SEARCH_PROFILE` is
  inspected first when set.
- Lock liveness is portable (`ESRCH` ⇒ dead, `EPERM` ⇒ alive, unknown ⇒ heartbeat decides); lock
  format unchanged (`version: 1`).
- Removed every `~/`/`$HOME`/`node:os`/`/proc/` offender from `config.ts`, `artifacts.ts`,
  `limiter.ts`, `browser.ts`, `discovery.ts`, `runtime/doctor.ts`, `cli/doctor.ts`, `index.ts`.
- Audit rule **R13** (host confinement) + `tests/unit/host.test.ts` (18 cases, three-platform matrix).
- `AGENTS.md` §8 one line; README documents the diagnostic platform override.
- Brand-aware hints: an Edge/Brave/Chromium endpoint no longer gets `chrome://inspect`.
