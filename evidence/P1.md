## Deviations

- The doctor necessarily holds the lock while it inspects: `lock.owner` is `self` (not "free"). The report
  says so instead of pretending the lock is free.
- `cdp.status:"error"` for `webdriver=true` (reachable but unusable) with a hint; `browser.ts` normally
  refuses earlier.
- The CLI closes only the window/tabs it opened on exit (`releaseAll`); the user's tabs are untouched.
- Window bounds persistence (SPEC §5.3 "remember in config") is **not implemented** in P1; the window uses
  Chrome's placement. Deferred to P7 polish or P4-C doctor work.
- DDG pagination deferred (M2 serves page 1, `pageIgnored:true`); see PLAN §5.1.
- Artifacts were pulled from P4-C into P3 (V3.6 needs snapshots at the P3 live gate); see PLAN §5.1.
