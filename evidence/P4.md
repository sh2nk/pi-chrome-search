## P4-C — what landed

- `createEngineProbe`: one cheap search per engine, serial, `summary:false`; reports `results`, `ai`,
  `canaries`, `wall`, `error`; a wall after a settle timeout is promoted to `wall` instead of `blocked`.
- Verdict mapping `ok|wall|layout_changed|blocked|unavailable`; all-zero canaries and `E_PARSE` →
  `layout_changed`; transport failures → `blocked`; probes skipped when CDP is not `ok` (honest note, not a
  fake success).
- `--fix`: reconnect once, close only owned tabs, prune artifacts, reclaim a stale lock only when the pid is
  dead and the connector did not answer `E_BUSY`; never `process.kill`, never a foreign tab.
- Deferred `web_doctor` tool: compact text report (<2500 bytes), details `{verdict, cdp, engines}`, params
  `{probe?, fix?}`, description 144 chars.
